# assets/audio ― 効果音の音声ファイル用(現在は空)

**効果音は音声ファイルを使っていない。** `src/audio.js` が Web Audio API で
その場で波形を合成している(`playTone` / `playSweep` / `playNoise` の3部品)。

爆発・被弾・警報・足音・文字送り ―― すべて合成。ファイルは1つも無い。

このフォルダは、**合成では作れない音が出てきたとき**のために空けてある。
実際に置くときは、ここに規約(命名・形式・音量の基準)を書き足すこと。

BGM は合成では作れないので、最初から音声ファイルを使う → `assets/bgm/`
