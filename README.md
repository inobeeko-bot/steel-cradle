# STEEL CRADLE ―鋼の揺り籠―

スペースコロニー争奪戦争を舞台にした、コックピット没入型・宇宙戦闘機ゲーム。

- 1戦闘10分の短期決戦。電力・熱・推進剤を配りながら戦う「操縦士 兼 機関士」ゲーム
- 三部作ストーリー(政治劇・結婚と子世代継承)+横スクロールの母艦生活パート
- 詳細仕様: [`docs/steel_cradle_setting.md`](docs/steel_cradle_setting.md)
- 原作小説: [`docs/steel_cradle_novel.md`](docs/steel_cradle_novel.md)

## 遊びかた

**`run.bat` をダブルクリックする。** ブラウザが開いて、黒い窓がサーバーになる。
遊び終わったら黒い窓を閉じる。

手で立てるなら、このフォルダで:

```
python dev_server.py 8765
```

を実行して <http://127.0.0.1:8765/> を開く。

`dev_server.py` は**ブラウザにキャッシュさせない**簡易サーバー。
素の `python -m http.server` でも動くが、そちらだと厄介な壊れ方をすることがある ――
新しい `.js` を足したのに古い `index.html` が使われると、そのファイルだけ
読み込まれず、**毎コマ例外が出て描画も敵AIも当たり判定も止まる**
(画面が真っ暗になり、敵がすり抜けて動かなくなる)。
`tick()` が例外を握り潰すので、コンソールにも出ない。
開発中はキャッシュを切っておくほうが、覚えることが減る。

### `index.html` を直接ダブルクリックしてはいけない

開くこと自体はできて、ほとんど動く。**しかしBGMだけが鳴らない。**

`file://` で開いたページは、ブラウザのセキュリティ制限で `fetch()` が使えない。
効果音は波形をその場で合成していてファイルが要らないので普通に鳴るが、
BGMは音声ファイルを読むので失敗する。**「効果音は鳴るのに音楽だけ鳴らない」
ときは、まずこれを疑う。**(気付けるよう、その場合はコンソールに理由を出す)

### フェーズ1の実装済み

- **飛行**:機首方向へ自動前進(速度=エンジンの電力配分に比例)、三人称視点、流れる宇宙塵
- **ドリフト**:Shift長押しで推力カット。慣性を保ったまま機首だけ回せる(振り向き撃ち)。ドリフト中は自然放熱2倍
- **姿勢**:W/S ピッチ・A/D ヨー・Q/E ロールの3軸(クォータニオン積分)。
  旋回は66度/秒(敵AIは126度/秒なので、まだ敵のほうが小回りが利く)。
  Q/E は1回押すと**きっちり90度**回って止まる ― 4回押せば必ず元の姿勢に戻る。
  等速では機械仕掛けに見えるので、立ち上がりと終わりぎわに大きく溜めを取ってある
  (押した1コマ目は34度/秒、そこから最高231度/秒まで上がって、0.57秒でぬるっと止まる)
- **バレルロール**(QQ / EE):同じ向きへ0.30秒以内に2回入れると、
  90度きざみをやめて**一気に1回転**する(450度を0.60秒・最高860度/秒)。
  回っている**0.60秒のあいだ、敵のビーム(曳光)を機体表面で弾く**。
  弾けるのは曳光だけで、**ミサイルと戦艦の大型ビームは通る** ―
  あちらはフレアと射線回避という別の答えが用意してあるため。
  推進剤−6・熱+4(仕様書9.3「急機動で消費」)。タダにすると回り続けるのが最適解になる。
  最終的な姿勢は1回押したときと同じ90度きざみのままなので、「4回で水平」の約束は崩れない
- **視点**:X で三人称 ⇄ コックピット。コックピットは内装シルエット+光像式照準器(リフレクターサイト)
- **主武器**(R で切替・F で発射):ビーム砲(6点バースト=引き金1回で6条・熱18・無限)/ 機関砲(240発・熱が軽い)/ ミサイル(ロック必須・1発撃墜)
- **BOMBS**(N で切替・B で投下):主武器とキーを分けてあるので、
  パイロで敵を止めた直後に切替なしでそのまま撃ち込める。**3種とも自分が巻き込まれる**
  ― パイロ弾(36発):熱50を入れ、14秒燃え続け、放熱を5分の1に落とす。
    直撃なら **6.1〜7.7秒で相手が強制シャットダウン**する(敵が撃てばもっと早い)。
    HPを削る力は3と低いまま ― 武器仕様書§3「ダメージ自体は低め」を守る
  ― ボム(8発):中心16の物理範囲ダメージ。半径36で距離減衰。
    **中心から23〜28以内なら撃墜**(以前は7.7以内で、範囲攻撃として成立していなかった)
  ― EMP(5発):**HPは1も削らない**(§3「キルは取れない」)。半径46・**7.5秒**行動不能。
    止めている7.5秒はビーム砲の引き金16回ぶん
- **弾道**:発射口は両翼。左右2条が**交会距離130**で1点に交わるよう内側を向く(ガン・ハーモナイゼーション)。
  照準もその点を指す。弾速200・寿命1.0秒で射程200。
  弾は**自機の前進ぶんを引き継ぐ**ので、どれだけ速く飛んでも自機から見た射程は変わらない
  (以前は引き継いでおらず、エンジン全開だと実効射程が88、回避バースト直後はほぼ0だった)
- **ミサイルの誘導**:赤外線シーカー。ロックした相手を追うのではなく、
  視野内の熱源を毎コマ見比べて「熱量 ÷ 距離²」がいちばん強いものへ向かう。
  フレアも、パイロ弾で燃えている機体も、この1本の式で説明される
- **回避装備**:フレア(自機の熱が高いと本体のほうが強く見えて騙せない)。敵側もミサイルとフレアを持つ
- **敵AI**:接近 / 攻撃 / 回避の3状態(HOUNDのみ離脱を足した4状態)。発射予告つき。
  敵にもHEATがあり、熱暴走で強制停止する
- **銃が当たること**:偏差(リード)の角度は `atan(敵の速度 ÷ 弾速)` で決まり、**距離に関係なく一定**。
  弾速90のころは12.5〜27.1度もあり、スコープの視野(x2で半角5.8度)を常に超えていた ―
  拡大するほど「敵とリード点を同時に見られない」状態だった。弾速200で5.7〜13.0度まで下がり、
  照準補助の錐(17.2度)にも収まる。
  実測(実AI・6通り×23秒・dtもばらつかせて)で**通算命中 90.2% → 98.9%**
- **当たり判定**:機体を組み立てている部品(翼・尾翼・胴体…)そのもので判定する。
  見た目のメッシュから自動で採寸するので、翼の角度を変えても判定は勝手について来る。
  以前は機体まるごとを楕円体1個で包んでいたが、実測すると見えている機体の
  6.9〜19.5%(HOUND の機首、SNIPER の尾翼)が撃っても当たらなかった ―
  いまは 0%。弾は1コマ分の線分で見るので、薄い翼をすり抜けることもない。
  当たりにくいと感じたら `src/scene.js` の `HITBOX.MARGIN` ひとつで全部品を太らせられる。
  戦艦は形が違うので別の作り(楔形+はみ出し部品20あまり)。艦体は前後48段に分けて張っており、
  これは見た目のためではなく当たり判定のため ―
  2段(8頂点)だと舷側の四角形がねじれて、判定が何も無い空間へ張り出していた。
  さらに断面の輪に中段の頂点を足して舷側を上下2枚に割り、48段まで刻んである ―
  実測で **舷側0.02 / 艦首0.02 / 甲板0.01 / 船底・艦尾0.00**(当初は舷側1.53・艦首1.33)。
  艦首がとくに厳しいのは舷側の面が進む向きとほぼ平行に寝ているためで、
  面から見たわずかなずれが進行方向には何倍にも見える。
  体当たりの余裕も 2.2→0.6 へ(舷側の即死圏は 6.7 → 3.8 に縮んだ)
- **偏差照準の安定**:敵の速度と加速度を、**直近0.24秒の軌跡に放物線を当てはめて**出す(最小二乗法)。
  1コマ差を2回引く方式は位置の2回微分になり、わずかな揺れが桁違いに増幅されていた。
  20点まとめて見るので点ごとの揺れが打ち消し合い、しかも「曲がっている」ことを式が持つので
  強くなましたときのような追従の遅れが出ない。
  印は「敵の現在位置 + 先読みぶん」で描き、**先読みぶんだけ**を最後に薄くなます。
  実測(実AI・6通り×23秒・dtもばらつかせて・1設定7300発):
  **1コマの揺れ 8.07px→1.99px / 最大の跳ね 225px→47px / 通算命中 88.2%→87.7%**
- **照準の自動追尾**(Z):追う相手を毎コマ選び直さない(25%以上ましな相手が現れて初めて乗り換える)。
  以前は同じくらいの角度に2機いるだけで追尾先が入れ替わり、機体が左右に振られていた。
  寄せる角速度自体にもなましを入れてある
- **センサー**:電力配分で索敵半径とロック時間が変わる。熱を出している敵は遠くからでも映る
- **被探知**:自機の熱とラジエーターの展開で「見つけやすさ」が決まり、
  敵の探知距離・弾道の先読み・散りがそれで変わる。
  ラジエーターは熱を下げる代わりに自分を目立たせる(熱55%ぶん相当)ので、
  開けっぱなしが最善にはならない
- **ロックオン**:ミサイル専用。銃(ビーム/機関砲)は軽い捕捉と偏差照準だけでロックしない。
  敵も同じで、ミサイルのロックは約35%の割合で撃たずに解く ―
  「来るかもしれない」を残すことで、有限のフレアを切るかどうかの読み合いにしている。
  警報は LOCK(ロックされた・来るかは不明)と MISSILE(発射済み)を分けて出す
- **計器**:レーダースコープ、敵マーカー、兵装パネル、ロックオン表示、偏差照準(小さな緑の印)
  コックピット視点では計器を canvas に描いて3Dの計器台に貼っている(`src/console3d.js`)。
  重ねているのではなく機体の一部なので、揺れ・傾き・遠近が勝手に付く。
  三人称視点はHTMLのオーバーレイのまま(同じ内容をデータパネルで出す)。
  余白には上級者向けの計器を置いている:
  HEAT BUDGET(発熱の内訳と差し引き)/ THREAT(狙われている段階と機数)/
  TARGET(敵の熱・放熱不能・残弾)/ FLIGHT DATA(シャットダウンまでの秒数・ロック進捗・
  横滑り角・距離・接近率・バースト残数・全兵装の残弾)/ MISSION(撃墜・被弾・シールド回復まで)。
  敵の残弾はセンサー配分40%以上のときだけ読める
  レーダーは高さを記号で表す(▲=自機より上 / ▼=下 / ◆=ほぼ同じ)。迫る敵ミサイルも映る
- **後方確認ミラー**:コックピット視点のみ。画面上部の小窓に機体の後方を映す。
  被弾で壊れる計器のひとつで、壊れると映像が切れて NO SIGNAL になる
- **照準スコープ**(O):機首の向きを拡大して右上の小窓に映す。両方の視点で使える。
  ビーム砲の射程198に対し、198先の敵は画面上でわずか12ドット ―
  一方で敵スナイパーは射程200・威力3.2倍で撃ってくるので、撃ち返す手段として入れてある。
  O を押すたび **2倍 → 4倍 → 6倍 → 閉じる**。
  ただし**索敵電力が上限を決める**(索敵0%で1倍/25%で2.2倍/50%で3.5倍/100%で6倍)。
  仕様書9.6が戦闘中のフルマップを禁じた理由「索敵電力の意味を守る」に合わせたもので、
  高倍率で狙うには索敵に電力を割く = 武器か盾か機関を削ることになる。
  選んだ倍率が索敵の上限を超えると `x3.5 / x6` と橙色で出る(足りていない、の意味)。
  窓には**レティクル**(十字+目盛り+四隅の括弧)と、**偏差照準**を重ねてある ―
  弾は敵の未来位置へ飛ぶので、拡大した窓の中にも「ここへ撃て」の印が要る。
  倍率を上げるほど視野は狭くなる(2倍で11度 / 6倍で3.7度)ので、
  遠くの速い横切りでは撃つべき点が窓から出る。そのときは印が**黄色い菱形**になって縁に寄り、
  どちらへ機首を振ればいいかを示す。
  ミラーと同じく被弾で壊れる計器のひとつ
- **背景のコロニー**:設計の違う2基が遠景に浮かぶ。どちらも回転で人工重力を作り、
  星と同じく自機について来るので、どこまで飛んでも空に浮かんだまま。
  ― 円盤型(スタンフォード・トーラス):小説のアルカディアと同じ作り。
    リング内壁に土、鏡面帆で軸から採光。見かけ50度で画面の横幅の7割を占める
  ― 円筒型(オニール・シリンダー):筒の内側全面に住む。長さ方向に陸と窓の帯が
    交互に走り、外に採光鏡が開く。見かけ30度。空の反対側(82度離れ)に置いてある
- **残骸回収**:撃墜すると残骸から機材が浮き出る(75%)。近づくと回収でき、戦闘中だけ効く。
  電力セル(発電量+20%)/ 冷却材(熱−35・放熱1.6倍。ラジエーターを開かないので見つからない)/
  推進剤 / シールド / 修理パーツ。戦艦の排熱口を潰すと確定で出る。
  設定の裏づけは `docs/salvage_system_v1.md`。弾数とHULLは回復しない(仕様書9.3の柱)
- **被弾**:シールド−15 → シールド0でHULL損傷 → 計器の機能低下、赤ビネット、画面揺れ。
  壊れても戦い続けられるようにしてある ―
  武器系は主武器3系統のうち1つだけ沈黙(BOMBSは別回路で生き残る)、
  **エンジン系は推力半減**(配分100%なら速度28。狙撃機14・汎用機の攻撃20は振り切れる)、
  センサー系は索敵半減。発熱も実際に出ている出力に比例するので、
  「壊されたほうが涼しい」といった抜け道は作らない
- **近接警告**:ぶつかりそうなものが近いと画面のふちが光る。遠い=黄でゆっくり、
  近い=赤で速く点滅。コックピットは距離感がつかめず、戦艦は触れたら即死なので入れてある
- **音**:Web Audio による効果音とエンジン音、`speechSynthesis` によるコックピット音声(F-16風)
- **機体スペック**(`src/ships.js`):乗っている機体で使える兵装と操縦の癖が変わる。
  制式機(TRAINING)と旧式艇四番機(物語の出撃)の2種。
  旧式艇の制限は私が決めた数字ではなく、**シーン3の台詞に書かれている内容をそのまま機能にしたもの**
  ―― 「実弾を積んだことは、一度もない」=ビーム砲のみ(2条・熱倍・間隔倍)、
  「右の推力偏向が渋い」=右へのヨーとロールだけ効きが弱く戻りが遅い
- **ミッション**:10分カウントダウン、10撃墜で MISSION COMPLETE、HULL5回で MISSION FAILED、時間切れで TIME UP、Enterで再出撃

## 操作

| 左手(操縦) | | 右手(資源管理) | |
|---|---|---|---|
| S / W | 機首上げ / 下げ | ↑←→↓ | 電力+10%(武器/盾/機関/索敵) |
| A / D | ヨー | 1 / 2 / 3 | プリセット 攻撃/防御/巡航 |
| Q / E | 急旋回ロール(1回で90度) | V | ラジエーター 展開→収納→自動 |
| QQ / EE | バレルロール(1回転・ビームを弾く) | | |
| F | 主兵装発射 | R | 主兵装の切替(ビーム/機関砲/ミサイル) |
| B | BOMBS を投下(パイロは連射可) | N | BOMBS の切替(パイロ/ボム/EMP) |
| C | フレア投下 | X | 視点切替(三人称 ⇄ コックピット) |
| | | O | 照準スコープの開閉 |
| Space | 回避バースト(推進剤−8・約2秒の加速) | Enter | 再出撃(リザルト表示中) |
| Shift長押し | ドリフト | Tab | 操作説明の開閉 |
| Z | 照準の自動追尾 入/切 | | |

ピッチ反転は `src/main.js` の `OPTIONS.invertPitch` で切り替え。
照準の自動追尾の強さは `src/scene.js` の `ASSIST` で調整できる(効き範囲9.2度・最大40度/秒)。
追尾が狙うのは機体の中心ではなく偏差照準の交会点なので、動く相手にも当たる向きへ寄る。

## 動かし方

ビルド不要。`index.html` をブラウザで開くだけ。

変更が反映されないときは `Ctrl + Shift + R`(強制再読み込み)。
画面上部に出るビルド番号(`src/main.js` の `BUILD`)で、どの版が動いているか確認できる。

## デプロイ

Cloudflare Pages が main ブランチへの push を自動デプロイする。

- ビルドコマンド: なし
- 出力ディレクトリ: `/`(リポジトリルート)
