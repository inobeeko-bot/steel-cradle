# STEEL CRADLE ―鋼の揺り籠―

スペースコロニー争奪戦争を舞台にした、コックピット没入型・宇宙戦闘機ゲーム。

- 1戦闘10分の短期決戦。電力・熱・推進剤を配りながら戦う「操縦士 兼 機関士」ゲーム
- 三部作ストーリー(政治劇・結婚と子世代継承)+横スクロールの母艦生活パート
- 詳細仕様: [`docs/steel_cradle_setting.md`](docs/steel_cradle_setting.md)
- 原作小説: [`docs/steel_cradle_novel.md`](docs/steel_cradle_novel.md)

### フェーズ1の実装済み

- **飛行**:機首方向へ自動前進(速度=エンジンの電力配分に比例)、三人称視点、流れる宇宙塵
- **ドリフト**:Shift長押しで推力カット。慣性を保ったまま機首だけ回せる(振り向き撃ち)。ドリフト中は自然放熱2倍
- **姿勢**:W/S ピッチ・A/D ヨー・Q/E ロールの3軸(クォータニオン積分)
- **視点**:X で三人称 ⇄ コックピット。コックピットは内装シルエット+光像式照準器(リフレクターサイト)
- **主武器**(R で切替・F で発射):ビーム砲(3点バースト・無限・熱が重い)/ 機関砲(120発・熱が軽い)/ ミサイル(ロック必須・1発撃墜)
- **BOMBS**(N で切替・B で投下):パイロ弾(炸裂して敵の放熱を止める・連射可)/ ボム(物理範囲ダメージ)/ EMP(範囲内を数秒沈黙させる)
  主武器とキーを分けてあるので、パイロで敵を止めた直後に切替なしでそのまま撃ち込める。3種とも自分が巻き込まれる
- **弾道**:発射口は両翼。左右2条が照準の先(300)で交わるよう内側を向く(ガン・ハーモナイゼーション)
- **ミサイルの誘導**:赤外線シーカー。ロックした相手を追うのではなく、
  視野内の熱源を毎コマ見比べて「熱量 ÷ 距離²」がいちばん強いものへ向かう。
  フレアも、パイロ弾で燃えている機体も、この1本の式で説明される
- **回避装備**:フレア(自機の熱が高いと本体のほうが強く見えて騙せない)。敵側もミサイルとフレアを持つ
- **敵AI**:接近 / 攻撃 / 回避の3状態。発射予告つき。敵にもHEATがあり、熱暴走で強制停止する
- **当たり判定**:機体は球ではなく楕円体(横に広く上下に薄い)。翼の外や真上の弾は当たらない
- **センサー**:電力配分で索敵半径とロック時間が変わる。熱を出している敵は遠くからでも映る
- **被探知**:自機の熱とラジエーターの展開で「見つけやすさ」が決まり、
  敵の探知距離・弾道の先読み・散りがそれで変わる。
  ラジエーターは熱を下げる代わりに自分を目立たせる(熱55%ぶん相当)ので、
  開けっぱなしが最善にはならない
- **ロックオン**:ミサイル専用。銃(ビーム/機関砲)は軽い捕捉と偏差照準だけでロックしない。
  敵も同じで、ミサイルのロックは約35%の割合で撃たずに解く ―
  「来るかもしれない」を残すことで、有限のフレアを切るかどうかの読み合いにしている。
  警報は LOCK(ロックされた・来るかは不明)と MISSILE(発射済み)を分けて出す
- **計器**:レーダースコープ、敵マーカー、兵装パネル、ロックオン表示、偏差照準(小さな緑の印)
  コックピット視点では計器を canvas に描いて3Dの計器台に貼っている(`src/console3d.js`)。
  重ねているのではなく機体の一部なので、揺れ・傾き・遠近が勝手に付く。
  三人称視点はHTMLのオーバーレイのまま(同じ内容をデータパネルで出す)。
  余白には上級者向けの計器を置いている:
  HEAT BUDGET(発熱の内訳と差し引き)/ THREAT(狙われている段階と機数)/
  TARGET(敵の熱・放熱不能・残弾)/ FLIGHT DATA(シャットダウンまでの秒数・ロック進捗・
  横滑り角・距離・接近率・バースト残数・全兵装の残弾)/ MISSION(撃墜・被弾・シールド回復まで)。
  敵の残弾はセンサー配分40%以上のときだけ読める
  レーダーは高さを記号で表す(▲=自機より上 / ▼=下 / ◆=ほぼ同じ)。迫る敵ミサイルも映る
- **後方確認ミラー**:コックピット視点のみ。画面上部の小窓に機体の後方を映す。
  被弾で壊れる計器のひとつで、壊れると映像が切れて NO SIGNAL になる
- **被弾**:シールド−15 → シールド0でHULL損傷 → 計器の機能低下、赤ビネット、画面揺れ
- **音**:Web Audio による効果音とエンジン音、`speechSynthesis` によるコックピット音声(F-16風)
- **ミッション**:10分カウントダウン、10撃墜で MISSION COMPLETE、HULL5回で MISSION FAILED、時間切れで TIME UP、Enterで再出撃

## 操作

| 左手(操縦) | | 右手(資源管理) | |
|---|---|---|---|
| S / W | 機首上げ / 下げ | ↑←→↓ | 電力+10%(武器/盾/機関/索敵) |
| A / D | ヨー | 1 / 2 / 3 | プリセット 攻撃/防御/巡航 |
| Q / E | 急旋回ロール(206度/秒・慣性あり) | V | ラジエーター 展開→収納→自動 |
| F | 主兵装発射 | R | 主兵装の切替(ビーム/機関砲/ミサイル) |
| B | BOMBS を投下(パイロは連射可) | N | BOMBS の切替(パイロ/ボム/EMP) |
| C | フレア投下 | X | 視点切替(三人称 ⇄ コックピット) |
| Space | 回避バースト(推進剤−8・約2秒の加速) | Enter | 再出撃(リザルト表示中) |
| Shift長押し | ドリフト | Tab | 操作説明の開閉 |

ピッチ反転は `src/main.js` の `OPTIONS.invertPitch` で切り替え。
照準の自動追尾の強さは `src/scene.js` の `ASSIST` で調整できる(効き範囲5度・17度/秒)。
追尾が狙うのは機体の中心ではなく偏差照準の交会点なので、動く相手にも当たる向きへ寄る。

## 動かし方

ビルド不要。`index.html` をブラウザで開くだけ。

変更が反映されないときは `Ctrl + Shift + R`(強制再読み込み)。
画面上部に出るビルド番号(`src/main.js` の `BUILD`)で、どの版が動いているか確認できる。
