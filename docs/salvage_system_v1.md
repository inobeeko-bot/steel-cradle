# STEEL CRADLE 残骸回収(サルベージ)設定 v1.0

**日付:** 2026-08-17
**位置づけ:** 設定資料本体(v1.0)への**追記候補**。神器コアとは別の「使い捨て機材」レイヤー。
`weapons_system_v1.md` が「基本武器」を神器の下の層として立てたのと同じ関係。

---

## 1. これは何か

撃墜した機体の残骸から、まだ生きている機材を回収して自機に回す。
効果は戦闘中のみの一時的なもので、出撃をまたいで残らない。

**神器(レガリア)ではない。** 神器は12基しか存在せず、製造もできず、
起動には聖印(DNA認証)が要り、入手経路は §9.5 で血統・結婚・ストーリー分岐に確定している。
雑兵が落とすようなものではない。ここで拾うのは、どの機体にも積まれている**ありふれた消耗機材**である。

## 2. 設定上の裏づけ

| 根拠 | 出典 | 何を担保するか |
|---|---|---|
| 「コアは奪取可能:**撃墜されればその場にドロップし、拾った側が奪える**」 | §6.1(決定済み) | **撃墜ドロップ+現地拾得**という挙動そのものが、すでにこの世界の正典 |
| 「マップに資源ポイント(**氷、精錬プラント、送電中継**)が点在」 | §9.4 モードA | 戦闘中に現地で資源を拾う遊びも正典 |
| 「旗艦=移動する拠点:リスポーン、**補給(推進剤・弾数・冷却)**」 | §9.4 モードB | 推進剤・冷却を補給するという概念が正典(通常の入手経路は自艦ドッキング) |
| 神器8 カシミール真空エネルギー変換炉「**唯一の『発電』神器**。僚機の排熱・電力問題を解決」 | §6.3 | **発電量を足す**という効果が正典に存在する。本レイヤーの電力セルは、その桁違いに劣る影 |
| 終わり屋(ニコライ・ヴォルコフ)「**戦場跡に必ず先回りして開く「店」**」 | §10.4 | 戦場跡を漁ることは、この世界では確立した商売である |
| 「三十年後、全コロニー群を維持する資源は枯渇する」 | 小説・ノルンの託宣 | 戦争そのものが資源枯渇の話。拾えるものを拾わない兵はいない |
| 「**停電とは、階級が可視化される現象の別名だ**」 | 小説・第二部 | 電力はこの世界における生存と階級の中心的象徴。電力セルが主役なのはそのため |

**誰がやるのか:** カイトたちは独立傭兵(§4)。母艦ペリカンは貧しく、
整備班の物資は「いつもどこからか届いた」(小説)。拾えるものを拾うのは、この隊の生活そのものである。

**倫理的な含み:** §8 第一部の転換点は「自分たちも『誰かの故郷』を落としていると気づく」。
落とした機体から部品を剥いで自分が生き延びる、という行為はその主題と地続きであり、
将来この主題を扱うときの素地になる。

## 3. 回収できるもの(4種)

§6.2 の方針「魔法的な謎兵器は禁止。実在の論文・研究に根拠を持つ」に合わせ、
4種とも実在技術に根拠を置く。神器と違い「理論上可能だが誰も作れていない」水準は要求しない ―
**現代の宇宙機ですでに使われている、ありふれた技術**であることがむしろ要点。

| # | 名称 | 効果 | 実在の根拠 |
|---|---|---|---|
| 1 | **電力セル** | 発電量 +20%(25秒)。配分の合計は100%のままで、各系統の実効出力が上がる | スーパーキャパシタ/フライホイール蓄電。いずれも実機で運用実績がある |
| 2 | **昇華型冷却材** | 熱 −35。加えて20秒間、放熱1.6倍。**ラジエーターを展開せずに冷える**ため被探知が上がらない | 水昇華式冷却器(アポロ・シャトル・ISS船外服で実用)/相変化材料(PCM)ヒートシンク |
| 3 | **推進剤タンク** | 推進剤 +25(満タンにはならない) | 破断タンクの残留推進剤(水/ヒドラジン) |
| 4 | **シールド蓄電体** | シールド +40(即時) | バリア発生器用の充電済みコンデンサバンク |

## 4. 触ってはいけないもの(設計の柱)

以下は本体仕様で明示されている柱であり、サルベージで覆してはならない。

- **弾数**:「実体弾系=弾数制で**リロード不可**」(§9.3)
  → **弾を補充するドロップは作らない。** 「弾切れ=終わり」は装備設計の芯(`weapons_system_v1.md` §1)
- **HULL**:「**戦闘中回復不可**」(§9.3)
  → **修理ドロップは作らない**
- **推進剤**:「10分で使い切る量に設定し、終盤の残量が読み合いになる」(§9.3)
  → 回復は**部分的**に留める。満タンにしない
- **電力の100%**:「合計100%を超えられない」(§9.3)。加えて §9.2 は、その壁が破れる瞬間を
  「レビヤタン最終戦…**いつものUIが化ける瞬間**」として三部作の山場に予約している
  → **配分UIの合計は100%のまま。上げるのは「発電量」のほう。**
    §9.3 の定義は「毎秒供給される**発電量**を4系統に手動配分」なので、
    100%はあくまで**発電した量の取り分**である。発電量が増えれば、同じ30%がより多くの出力になる。
    仕様の文言も、山場の一回性も、これで両方守られる

## 5. 熱の扱いについて(いちばん設計的に効く点)

§9.3 の中核ジレンマは「冷やしたいが今冷やすと危ない」―
ラジエーターを展開すれば冷えるが、そのぶん敵に見つかる。

昇華型冷却材は、**展開せずに冷やせる**唯一の手段になる。
これはジレンマを消すのではなく、**稀な逃げ道を一つ置く**だけである:

- 有限(撃墜しないと出ない)
- 拾いに行かなければ手に入らない(その間は戦えない)
- 効果時間が切れれば元のジレンマに戻る

「持っているうちは強気に撃てる」という選択が一つ増える、という位置づけ。
