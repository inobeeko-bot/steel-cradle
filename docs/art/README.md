## パレット原器 ― 背景だけのもの

**原器は背景のためのもので、マップごとに1つ。**
人物にはパレットではなく「陰影の作法」を使う（下記）。
考え方の詳細は `assets/adv/ASSETS.md` の「パレット規約」を参照。

| ファイル | 対象 | 色数 |
|---|---|---|
| `bg_hill_master.png` | シーン1 林檎の丘（夕景）の背景 | 48 |
| `bg_hill_night_master.png` | シーン2 収穫祭の夜の背景 | 48 |
| `palette_hill_night.json` / `.gpl` | 上の夜の原器を色一覧にしたもの | 48 |

`.gpl` は GIMP / Aseprite が読める形式。手直しの前にこれを読み込ませておけば、
原器の外の色を使ってしまう事故が起きない。
規則を覚えておくのではなく、道具の側で守れなくする。

`assets/adv/maps/<マップ>/` の far / mid / near は、その原器の絵を層に分けたもの。

### `palette_char_ramp.json` は使わない

かつて「人物・小物は全マップ共通のこの32色で作る」としていたが、
**その規約は守れないことが実測で分かった**（32色中28色が暖色で、
守ると全キャラが茶色になる。既存のカイトと祖父はそもそも色を1つも共有していない）。

人物は色の一覧ではなく `pixel_kobo/shading/hill.json` の
**陰影の作法**（暗いほど紫へ、明るいほど黄へ）に従って作る。
ファイル自体は経緯の記録として残してあるが、規約としては使わない。

### 新しいマップの原器の作り方

**既存の原器を色替えするのではなく、新しく生成した絵から48色を抽出する。**

丘の原器は全部暖色なので、夜や屋内の絵には根本的に合わない。
無理に寄せると色が濁る（実測：夜の絵を丘の原器へ寄せると色域のずれ76.2、
その絵から作った原器なら11.5）。

```
cd ../development_aids/pixel_kobo
python kobo.py palette from-image raw/<生成した絵>.png --name <マップ名> --size 48
```

## preview_*.png ― 制作途中の確認用

納品時に内容を確認するために作られた見本。
ゲームは読み込まない。並び順やコマの中身を後から見返すために残してある。

| ファイル | 内容 |
|---|---|
| `preview_composite.png` | 背景3層を合成した完成見本 |
| `preview_kite.png` | カイトを背景に並べた配置見本 |
| `preview_kite_walk_v4.png` | カイトの歩行4コマ |
| `preview_grandpa_walk_v4.png` | 祖父の歩行4コマ |
| `preview_prop_ladder_v3.png` / `preview_ladder4.png` | 脚立 |

ファイル名に残っている `_v3` / `_v4` は納品時の版数。
`assets/` 側は版数を落とした正式名で運用している（`ASSETS.md` 参照）。
