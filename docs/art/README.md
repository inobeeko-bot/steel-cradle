## bg_hill_master.png ― 第1章 公式パレット原器

**第1章（アルカディア／林檎の丘）のパレット原器。**
640×360、実測で **48色ちょうど**（透明部分を除く）。

第1章の新しい素材は、すべてこの48色に寄せて作る。
原器に無い色を足すと、同じ画面に並べたときそこだけ浮いて見える。

`assets/adv/maps/hill/` の far / mid / near は、この絵を層に分けたもの。

夜Ver（シーン2）のように時間帯が変わるときは、この原器を色替えして
新しい原器を作り、そのマップの素材はすべて新しい原器に寄せる。
